# Mini-projeto de exemplo

Este exemplo existe para mostrar o fluxo, não para ensinar Python.

```text
data/sample.csv
      ↓
src/analyze.py
      ↓
results/
      ↓
docs/report.md
```

Execute:

```bash
python src/analyze.py
```

Depois abra `docs/report.md`.

Com MyST instalado, por exemplo:

```bash
myst build docs/report.md --pdf
```
